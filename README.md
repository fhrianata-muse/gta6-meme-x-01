Entry for make.fun's "Post a GTA 6 meme on X" bounty. The meme is a two-panel
comic: in 2013 a young gamer waits for GTA VI next to the make.fun ghost, and in
2026 the same gamer has aged into a white-bearded grandfather while the ghost
has not aged at all — "EVERYONE AGED WAITING. THE GHOST DIDN'T." It was posted
publicly on X by @expylar: https://x.com/expylar/status/2123808315797131690
The post's text carries make.fun, a tag of @makefunai, and the entrant's
make.fun play code. This repository hands in the post's address: `main.ts`
copies `POST.json`, which names the post, into the output directory where the
make.fun gate reads it.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
